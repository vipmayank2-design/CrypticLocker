Security & Cryptographic Architecture

Deterministic, tamper-resistant encryption standards protecting every file and folder.

Authenticated Encryption

All vault assets are individually encrypted with AES-256-GCM (Authenticated Encryption with Associated Data). Each container includes a 128-bit authentication tag ensuring any unauthorized storage modification is instantly detected.

Argon2id Key Derivation

Master password derivation is hardened via Argon2id, the winner of the Password Hashing Competition. It provides superior resistance against GPU and specialized ASIC brute-force hardware attacks.

CLV2 Binary Container Standard

Every file is compartmentalized in a standalone CLV2 binary container with encrypted inner metadata, unique per-file initialization vectors (IVs), and high-throughput streaming encryption.

Ephemeral Memory Lifetime

Decrypted Master Keys and key material exist strictly in volatile memory during active sessions. Keys are immediately zeroed and purged upon manual locking, timeout, or system sleep.

Adaptive Hardware-Aware I/O Acceleration

Dynamic memory-tier scaling, high-throughput chunk streaming, and kernel syscall optimization.

Dynamic Hardware Profiling

Automatically probes host physical RAM and CPU topology at startup, calculating optimized streaming buffer tiers from a 512 KB baseline for 4 GB laptops up to 64 MB for enterprise workstations.

Up to 600% Speed Acceleration

Replaces legacy 64 KB streaming bottlenecks with hardware-scaled buffers, achieving over 200 MB/s to 1,000+ MB/s real-world encryption and extraction throughput on modern NVMe storage arrays.

1024x Syscall Reduction

Drastically reduces operating system kernel context switches (Ring 3 ⇄ Ring 0) by up to 1024x per Gigabyte transferred, eliminating CPU lockups and thread thrashing during heavy workloads.

Sub-Millisecond V8 Safety

Streaming allocations are strictly clamped below 0.05% of available system memory, keeping V8 Garbage Collection pause times under 1 ms with zero OS virtual memory page swapping.

Privacy & Data Sovereignty Principles

Strict privacy guarantees ensuring zero external exposure of your personal data.

Zero Telemetry & Analytics

CrypticLocker does not contain tracking scripts, usage telemetry, analytical SDKs, or background crash reporters. Your usage patterns and file operations remain entirely private to your device.

100% Offline Vault Storage

The desktop application operates in complete network isolation with a strict connect-src 'none' Content Security Policy. Encrypted data never touches external servers or cloud services.

Autonomous Quarantine & Repair

An integrated autonomous Quarantine Manager actively safeguards against accidental filesystem renames and corruption, offering non-destructive container inspection and safe recovery.

Pure Zero-Knowledge Guarantee

CrypticLocker does not have backdoors, master master-keys, or central escrow mechanisms. Your encrypted files are decipherable solely through your Master Password or Recovery Key.

Legal Disclosures & Responsible Security

Terms of security responsibility and software licensing notices.

User Credential & Key Responsibility

Because CrypticLocker enforces a strict Zero-Knowledge cryptographic model, password recovery cannot be performed by any external entity or software vendor. Users must securely archive their Recovery Key. Loss of both the Master Password and Recovery Key will result in mathematically irreversible data loss.

Open-Source Frameworks & Libraries

CrypticLocker is built using high-performance open-source technologies including Electron, Chromium, and Node.js Crypto. All third-party software dependencies are governed by their respective permissive licenses (MIT, BSD, Apache 2.0).
